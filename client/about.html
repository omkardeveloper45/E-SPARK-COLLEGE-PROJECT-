E-SPARK – EV Charging & Billing System

Semester 5 Software Engineering Comprehensive Full-Stack Capstone System

Project Objective & Architecture

E-SPARK is an end-to-end web software platform engineered to streamline electric vehicle (EV) charging station discovery, slot reservation, live telemetry monitoring, multi-channel payment processing, and automated tax invoice generation.

Frontend Stack

  • HTML5 Semantic Structure
  • CSS3 Utility & Custom Theme System
  • Vanilla JavaScript (ES6+ AJAX API Client)

Backend & Database Stack

  • Node.js & Express.js MVC Framework
  • MongoDB & Mongoose Data Models
  • JWT (JSON Web Tokens) & bcrypt Encryption
